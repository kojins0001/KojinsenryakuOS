# 概念設計と集合知

新しい概念は、誰か一人の頭の中で完成するものなのでしょうか。

私はむしろ、**概念は集合知の中に投入されることで進化するのではないか**と考えています。

概念設計者ができるのは、最初の「変異」を作ることです。

既存の概念を組み合わせる。
異なる分野を接続する。
新しい分類を作る。
これまで存在しなかった問いを提示する。

しかし、その概念が本当に価値を持つかどうかは、設計者一人では決められません。

## 概念にも淘汰圧がある

社会に投入された概念は、人々に使われ、批判され、改変され、別の概念と接続されます。

その過程で、残る概念と消えていく概念が生まれる。

つまり、

**概念生成 → 社会への投入 → 集合知による評価 → 改変 → 淘汰**

という改善ループが成立するのではないでしょうか。

これは生物進化と少し似ています。

生物には環境からの淘汰圧が存在するように、概念にも「社会に残れるか」という淘汰圧が存在する。

ただし、概念の場合、その環境は自然環境ではありません。

人間の認知、文化、経済、技術、制度、メディア、そしてAIなどが相互作用する**情報生態系**です。

ここでは、単純に「正しい概念」が残るとは限りません。

理解しやすい。
使いやすい。
予測に役立つ。
他の概念と接続しやすい。
新しい行動を生み出す。

こうした性質を持つ概念ほど、情報生態系の中で増殖しやすい可能性があります。

すると概念設計者の役割も変わってきます。

「完成した概念を発表する人」ではなく、

**集合知に新しい概念の変異を投入し、その反応からさらに改良する人**

と考えることができます。

特にAIエージェントが大量に参加するようになれば、このループはさらに高速化するかもしれません。

一つの概念に対して、AIが異なる解釈を生成し、異なる分野との接続を探索し、反証や応用可能性を検証する。

その結果を再び概念設計に戻す。

すると、概念そのものが「静的な作品」ではなく、**集合知によって進化する情報単位**になっていく可能性があります。

ただし、ここには重要な問題もあります。

淘汰されることと、価値がないことは同じではありません。

短期的には理解されにくい概念が、数十年後に重要になることもある。

だからこそ、概念設計では「現在の人気」だけではなく、**将来どの探索空間を開く可能性があるか**まで考える必要があるのかもしれません。

概念にも淘汰圧がある。

そして概念設計とは、その淘汰圧から逃れることではなく、**集合知との相互作用によって、より強い概念へ進化させるための出発点を作ること**なのかもしれません。
