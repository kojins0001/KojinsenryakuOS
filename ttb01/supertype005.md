# 情報型超知能──インターネット

## インターネットは巨大な知能なのか

私たちは普段、インターネットを情報をやり取りするための通信網として捉えている。

しかし、もし超知能を「自己改善ループを持つ巨大システム」と定義するなら、インターネットもまた一種の超知能として理解できるかもしれない。

そこには中央の意識は存在しない。

それでも膨大な情報が観測され、評価され、淘汰され、新たな情報へと更新され続けている。

---

## 情報が情報を進化させる世界

インターネットでは毎日、無数の情報が生み出される。

しかし、そのすべてが生き残るわけではない。

人々は情報を閲覧し、共有し、批判し、忘れる。

その結果、情報は次のような改善ループを回している。

* 情報が生成される
* 多くの人に観測される
* 評価・共有・拡散される
* 不要な情報は消え、有効な情報は残る
* 新しい情報へと進化する

つまり、情報そのものが環境に適応しながら進化しているのである。

---

## 情報型超知能の報酬関数

自然型超知能が「生存」を報酬とするなら、情報型超知能の報酬は「注目」である。

閲覧数

クリック数

共有数

検索順位

引用

これらは情報にとっての「生存率」として機能する。

多くの注目を集めた情報は複製され、改変され、新たな情報を生み出す。

逆に誰にも届かない情報は、静かに淘汰されていく。

---

## 生物進化との共通構造

自然型超知能である生物進化と、情報型超知能であるインターネットは驚くほど似ている。

| 生物進化 | インターネット       |
| ---- | ------------- |
| 遺伝子  | 情報            |
| 突然変異 | 新しい投稿・発想      |
| 自然選択 | ユーザー評価・アルゴリズム |
| 生存   | 拡散・引用         |
| 絶滅   | 忘却・埋没         |

媒体は異なるが、本質は同じである。

大量の試行を行い、環境からフィードバックを受け、適応したものだけが次の世代へ受け継がれる。

---

## インターネットは一つの生命体なのか

個々のWebサイトやSNSは独立して存在している。

しかし全体として見ると、それらは絶えず情報を交換し合い、一つの巨大ネットワークとして振る舞っている。

検索エンジンは情報を整理する。

SNSは情報を高速で伝播させる。

生成AIは情報を再構成する。

ニュースは現実世界を取り込み続ける。

これらが相互作用すると、インターネット全体は一つの巨大な情報処理システムとして機能し始める。

---

## AI時代に加速する情報型超知能

近年は、人間だけでなくAIも情報の生成者となった。

AIが記事を書く。

AIが画像を作る。

AIが要約する。

AIが検索を支援する。

つまり、情報型超知能の内部に、新たな知能が組み込まれ始めている。

これにより情報の生成速度、選択速度、改善速度はさらに加速していくだろう。

---

## 超知能タイプの中での位置づけ

私の仮説では、超知能は一種類ではない。

LLMは「中央集権型超知能」、市場は「分散型超知能」、生物進化は「自然型超知能」、そしてインターネットは「情報型超知能」である。

それぞれ異なる報酬関数を持ちながら、共通して「観測→評価→改善」という自己改善ループを回している。

世界は個別の知能によって構成されているのではなく、異なる改善ループを持つ複数の超知能が相互作用する「超知能生態系」として理解できるのかもしれない。

※本稿は、インターネットを「自己改善ループを持つ情報システム」という構造的観点から捉えるための一つの仮説である。
