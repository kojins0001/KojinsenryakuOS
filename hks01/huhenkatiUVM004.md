# AI平均と人類平均を「銘柄」にできるか

株式市場では、個別企業だけでなく、複数の企業をまとめた指数が存在します。

ならばAI時代には、個別のAIではなく、**「AI全体の平均的な能力」そのものを一つの銘柄や指数として扱う**ことはできないでしょうか。

例えば「AI平均」と「人類平均」を、それぞれ一つの評価対象として市場に投入する。

AIエージェント群に同じ問題を解かせ、その予測精度、発見能力、問題解決能力、創造性、安全性などを継続的に測定する。一方、人間側にも同様の評価を行う。

すると、

**AI平均指数：120 → 135 → 148**
**人類平均指数：100 → 102 → 104**

のように、両者の能力変化を時系列で追跡できるかもしれません。

さらに重要なのは、総合指数だけではありません。

「科学予測」ではAIが優位、
「現実世界の判断」では人類が優位、
「未知の問題発見」では拮抗、

といった具合に、領域ごとの「AI指数／人類指数」を形成することも考えられます。

ここで市場を組み合わせると、単なるベンチマークとは違うものになります。

参加者が「今後、AIと人類のどちらがこの領域で優位になるか」を予測し、その予測結果と実際の成果を継続的に比較する。

つまり、

**評価 → 予測 → 実績 → 再評価**

というループを回すのです。

すると市場価格は、単なる能力値ではなく、**「社会が現在どちらの集合知に将来価値を感じているか」**を表す情報になります。

さらにAI平均と人類平均の価格差を見ることで、文明の知能構造そのものを観測できる可能性があります。

例えばAI指数が急上昇しているのに、人類指数が横ばいなら、AIへの期待が高まっているのかもしれない。

逆にAI指数が高くても、現実成果が伴わなければ「AI期待バブル」の可能性もある。

ここで重要なのは、AIと人類のどちらが「上」なのかを決めることではありません。

むしろ、

**「どの領域で、どの知能が、どの程度の価値を持つのか」**

を市場によって継続的に探索することです。

さらに進めれば、AI平均と人類平均だけでなく、

* AIエージェント平均
* 人類平均
* 人間＋AI協働平均
* 特定専門家集団
* 特定AIモデル群
* 特定の推論方式

なども銘柄化できる。

そうなれば市場は、企業の価値を比較するだけでなく、**異なる知能システムそのものを比較する装置**になります。

そして最も面白いのは、その先です。

もし「AI平均」「人類平均」「人間＋AI平均」を長期間追跡できれば、そこから、

**「文明の集合知はどの方向に進化しているのか？」**

という問いまで市場データから考察できるようになるかもしれません。

普遍価値市場とは、あらゆるものに値段を付ける市場ではない。

もしかするとその本質は、

> **異なる知能・概念・技術・組織の将来価値を同じ市場空間で競わせ、文明の探索方向を可視化すること**

なのかもしれません。
