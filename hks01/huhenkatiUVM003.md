# 「お金」ではなく「信用・予測能力」を取引する

金融市場では、基本的に「お金を持っていること」が市場参加能力の一つになる。

しかし、AIが普及し、さらにASIのような高度な知能が登場した未来では、別の資源の価値が上昇するかもしれない。

それが、

**「何を予測できるか」
「どれだけ予測を当ててきたか」
「どれだけ信頼できるか」**

という能力である。

例えば、ある人が「3年後にこの技術が重要になる」と予測したとする。

その予測が何度も的中すれば、その人の予測能力そのものに信用が蓄積されていく。

一方、予測を繰り返し外す主体の信用は低下する。

ここで、

**予測 → 結果 → 検証 → 信用更新**

というループが形成される。

すると、市場参加者の「お金」だけでなく、**予測実績から形成された信用そのものが資本として機能する**可能性がある。

例えば、

「この人は未来の技術動向を予測するのが得意」

「このAIエージェントは科学的仮説の評価精度が高い」

「この集団は10年先の社会変化について継続的に高い予測精度を示している」

といった評価が、数値化される。

そして、その信用スコアや予測実績をもとに、より大きな探索資源や意思決定権が与えられる。

これは金融市場における「資本の複利」と少し似ている。

金融では、利益を上げれば資本が増え、次の投資機会が増える。

予測市場では、予測を当てれば信用が増え、より重要な予測や意思決定に参加できる。

つまり、

**お金の複利 → 信用の複利**

という構造が生まれるかもしれない。

さらに重要なのは、信用を「肩書き」ではなく、**予測履歴から継続的に更新される動的な情報**として扱うことだ。

例えば、

* 予測精度
* 予測期間
* 分野別の得意領域
* 不確実性の見積もり
* 過去の判断の一貫性
* 他の予測者との差異
* 実際の成果との乖離

などを記録する。

すると「この人は賢い」という曖昧な評価ではなく、

**「この人は、この領域の、この時間スケールの予測に強い」**

という、より精密な信用が形成される。

そしてAIエージェントが大量に参加すれば、この仕組みはさらに面白くなる。

AIエージェントAは科学予測に強い。

AIエージェントBは市場予測に強い。

AIエージェントCは長期的な社会変化の予測に強い。

人間Dは、AIが見落とす少数派の可能性を発見するのが得意。

このような異なる予測能力を持つ主体を同じ市場に投入し、実績によって信用を更新していく。

すると市場は、単なる「お金の競争」ではなく、

**予測能力の競争と発見の場**

になっていく。

さらに、その信用を資源配分に利用できるかもしれない。

「誰に研究資金を配分するか」

「どの技術に投資するか」

「どの仮説を検証するか」

「どのAIエージェントに探索を任せるか」

といった意思決定に、過去の予測実績を組み込む。

そうなると、普遍価値市場は、

**資本を持つ者が有利な市場**

から、

**未来をより正確に予測し、価値を発見できる者が信用を蓄積する市場**

へ変化する可能性がある。

ただし、ここにも重要な注意点がある。

予測精度が高いことと、社会的に望ましいことは同じではない。

また、短期予測が得意な主体が、長期的に重要な価値を持つとは限らない。

したがって必要なのは、単一の「信用スコア」ではなく、

**予測能力・実績・分野・時間軸・不確実性・社会的影響**

などを分解した多次元的な信用評価なのかもしれない。

もしこれが実現すれば、「お金」は価値交換の唯一の尺度ではなくなる。

その代わりに、

**「この主体は、未来についてどれだけ信頼できる情報を生み出せるのか？」**

という能力そのものが、新しい資本になる。

普遍価値市場とは、最終的には「お金を持つ者が価値を決める市場」から、

**「価値を発見できる者に、より多くの探索機会が与えられる市場」**

への転換なのかもしれない。
